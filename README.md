## Предметы

### Артефакты

Артефакты делятся по типу: **запечатанные артефакты** (опасные предметы под надзором Церквей, с идентификатором вида `0-08`), **талисманы** (защитные и вспомогательные предметы) и **прочие артефакты**. Записи, тип которых пока не уточнён, остаются в разделе «Прочие артефакты».

#### Запечатанные артефакты

Идентификатор оформляется как inline-код (см. [правило 1.8](#оформление--артефакты)).

- <abbr title="Angel of Concealment">Ангел Сокрытия</abbr> `0-17` (гл. 917)

## Правила оформления

<a name="оформление--метаданные"></a><a name="1.0"></a>

### Метаданные главы

- [1.0](#оформление--метаданные) Каждый файл главы начинается с YAML frontmatter, где указываются переводчик и редактор.

  ```md
  ---
  translator: Vox Mundi
  editor: Имя Редактора
  ---
  ```

  - `translator` — имя переводчика главы.
  - `editor` — имя редактора главы.

  Если переводчик или редактор не указан, поле опускается.

**[⬆ наверх](#содержание)**

<a name="оформление--заголовок-главы"></a><a name="1.1"></a>

### Заголовок главы

- [1.1](#оформление--заголовок-главы) Заголовок главы оформляется как заголовок первого уровня. Номер и название разделяются точкой.

  ```md
  # Глава 663. Название
  ```

**[⬆ наверх](#содержание)**

<a name="оформление--тире"></a><a name="1.2"></a>

### Тире в тексте

- [1.2](#оформление--тире) Тире внутри повествовательного текста (перечисления, пояснения, вводные конструкции) оформляется двумя дефисами ` -- ` с пробелами. Pandoc преобразует их в короткое тире `–` при сборке.

  > Почему? Прямой символ `—` в исходнике труднее отличить от дефиса при редактировании. ` -- ` визуально явный и единообразный.

  **Плохо:**

  ```md
  западная часть — Республике Интис, а территория на востоке — Королевству Лоэн.
  ```

  **Хорошо:**

  ```md
  западная часть -- Республике Интис, а территория на востоке -- Королевству Лоэн.
  ```

**[⬆ наверх](#содержание)**

<a name="оформление--диалог"></a><a name="1.3"></a>

### Диалог

- [1.3](#оформление--диалог-без-атрибуции) Реплика без атрибуции начинается с `---` и занимает отдельный абзац.

  ```md
  --- Текст реплики.
  ```

- [1.4](#оформление--диалог-с-атрибуцией) Если за репликой следует атрибуция или действие персонажа, они добавляются в ту же строку через ` --- `.

  > Почему? Это сохраняет реплику и её атрибуцию единым визуальным блоком, не разрывая читательский ритм.

  **Плохо:**

  ```md
  --- Текст реплики.

  Персонаж сделал что-то.
  ```

  **Хорошо:**

  ```md
  --- Текст реплики. --- Персонаж сделал что-то.
  ```

  Если после действия реплика продолжается, продолжение добавляется в ту же строку через ` --- `:

  ```md
  --- Первая часть реплики. --- Персонаж помолчал и добавил. --- Продолжение реплики.
  ```

- [1.4б](#оформление--диалог-с-предшествующим-действием) Если атрибуция или действие персонажа **предшествует** реплике, формат зависит от длины атрибуции.

  Краткое физическое действие — реплика в той же строке через ` --- `:

  ```md
  Сьельф пожал плечами. --- Считай, повезло тебе.
  ```

  Развёрнутая атрибуция или глагол речи — атрибуция завершается двоеточием и занимает отдельный абзац; реплика открывает новый абзац:

  ```md
  Андерсон сказал с усмешкой:

  --- Не нужно говорить «не в ладах»...
  ```

**[⬆ наверх](#содержание)**

<a name="оформление--мысли"></a><a name="1.5"></a>

### Мысли

- [1.5](#оформление--мысли-текст) Внутренние мысли персонажа оформляются курсивом в кавычках-ёлочках.

  ```md
  *«Кровь?»*
  ```

- [1.6](#оформление--мысли-атрибуция) Атрибуция или действие после мысли добавляются в ту же строку через ` --- `.

  **Плохо:**

  ```md
  *«Текст мысли.»*

  Персонаж сделал что-то.
  ```

  **Хорошо:**

  ```md
  *«Текст мысли.»* --- Персонаж сделал что-то.
  ```

- [1.6б](#оформление--мысли-телепатия) Речь, звучащая в голове персонажа извне (телепатия, голос существа-паразита и т.п.), заключается в экранированные квадратные скобки `\[...\]` внутри кавычек-ёлочек.

  ```md
  *«\[Парень, тебе важное письмо.\]»*
  ```

**[⬆ наверх](#содержание)**

<a name="оформление--звуки"></a><a name="1.7"></a>

### Звуки

- [1.7](#оформление--звуки) Звуковые эффекты и ономатопея оформляются символом `♫` без курсива.

  **Плохо:**

  ```md
  *Бах! Бах! Бах!*
  ```

  **Хорошо:**

  ```md
  ♫ Бах! ♫ Бах! ♫ Бах!
  ```

  Таблица переводов:

  | Оригинал | Перевод |
  |---|---|
  | Whoosh! | ♫ У-у-у! / ♫ Ф-ш-ш! |
  | Phew! | ♫ Фух! |
  | Bam! | ♫ Бах! |

<a name="оформление--клуб-таро"></a><a name="1.10"></a>

### Члены Клуба Таро

- [1.10](#оформление--клуб-таро) Обращения к членам Клуба Таро по роли карты заключаются в экранированные квадратные скобки `\[Название\]`. Экранирование обязательно, чтобы markdown не интерпретировал скобки как ссылку.

  **Плохо:**

  ```md
  [Повешенный] и [Мир] согласились на условия Деррика.
  ```

  **Хорошо:**

  ```md
  \[Повешенный\] и \[Мир\] согласились на условия Деррика.
  ```

- [1.11](#оформление--клуб-таро) Правило распространяется на все контексты: повествование, диалог и мысли.

  ```md
  *«\[Солнышко\], да ты простофиля!»* --- мысленно усмехнулся он.
  ```

<a name="оформление--пути"></a><a name="1.12"></a>

### Пути и Последовательности

- [1.12](#оформление--пути) Названия Путей пишутся с заглавной буквы в форме «Путь [Название]».

  **Плохо:**

  ```md
  путь смерти, путь гиганта
  ```

  **Хорошо:**

  ```md
  Путь Смерти, Путь Гиганта, Путь Бога Сражений
  ```

- [1.13](#оформление--пути) Названия ролей (ступеней) внутри Пути пишутся с заглавной буквы.

  ```md
  Привратник, Охотник на Демонов
  ```

- [1.14](#оформление--пути) Номер Последовательности указывается в форме `[N]-й Последовательности` перед названием Пути.

  **Плохо:**

  ```md
  Привратник 5 последовательности пути смерти
  ```

  **Хорошо:**

  ```md
  Привратник 5-й Последовательности Пути Смерти
  ```

## Правила оформления README

### Персонажи и термины

- Имена персонажей, названия мест, предметов и последовательностей добавляются при первом появлении в переводе.
- Сортировка внутри списков — по алфавиту.

### Английский оригинал

- Английское название термина указывается через тег `<abbr>` — оно отображается как всплывающая подсказка при наведении:

  ```md
  <abbr title="Английский оригинал">Русский перевод</abbr>
  ```

### Глава первого появления

- Глава, в которой термин встречается впервые, указывается в скобках после названия:

  ```md
  <abbr title="Fate Siphon">Сифон Судьбы</abbr> (гл. 771)
  ```

### Артефакты по типу

- Новый артефакт добавляется в один из подразделов раздела «Артефакты»:
  - **Запечатанные артефакты** — предметы под надзором Церквей с идентификатором; идентификатор оформляется как inline-код, например `Перо Альзухода \`0-08\``.
  - **Талисманы** — защитные и вспомогательные предметы (charm → «талисман», не «амулет»), например Сифон Судьбы.
  - **Прочие артефакты** — всё остальное и записи, тип которых пока не уточнён.

### Адреса и улицы

- Улицы и конкретные адреса добавляются как вложенные пункты под соответствующим городом в разделе «Города»:

  ```md
  - Бэклунд
    - Улица Пинстер, 7
  ```
